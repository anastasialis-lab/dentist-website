# U&S Dental Clinic — сайт

Статичний односторінковий сайт стоматологічної клініки U&S (Львів, вул. Замарстинівська 55Є).

## Локальний перегляд

Сайт не потребує збірки — це чистий HTML/CSS/JS.

```bash
# Python (є майже всюди)
python3 -m http.server 8000

# або Node
npx http-server -p 8000
```

Далі відкрийте <http://localhost:8000>.

> Просте відкриття `index.html` через `file://` теж працює, але карта Google
> та частина шрифтів можуть не завантажитись — краще через локальний сервер.

## Структура

| Файл | Призначення |
|---|---|
| `index.html` | Уся розмітка сторінки |
| `styles.css` | Дизайн-система 2.0 (токени, компоненти, секції, анімації) |
| `script.js` | Хедер, мобільне меню, scroll-reveal, паралакс, лічильники, таби прайсу, FAQ |
| `styles.legacy.css` | Архів попередніх стилів. **Не підключений** — залишений для довідки |
| `fetch-media.sh` | Завантажує згенеровані фото до `img/ai/` і робить сайт самодостатнім |
| `img/` | Фотографії клініки та логотип |

## Дизайн-система

Усі токени — у блоці `:root` файлу `styles.css`.

- **Акцент:** приглушений медичний синій `--blue-500: #6E9DB8` (світліша й менш
  насичена версія кольору зуба з логотипа), глибокий `--blue-700: #2C5A72`.
- **Типографіка:** `Manrope` для інтерфейсу, `Cormorant Garamond` (italic) для
  акцентних слів у заголовках.
- **Форма:** великі радіуси (20–36px), майже безбарвні м'які тіні, багато
  білого простору, секції по `clamp(76px, 9vw, 140px)` вертикалі.

### Анімації

Декларативні, через атрибути в розмітці:

```html
<div data-reveal="up">…</div>          <!-- up | down | left | right | scale | fade | mask -->
<div data-stagger="110">…</div>        <!-- каскадна затримка для дочірніх data-reveal -->
<div data-parallax="0.12">…</div>      <!-- множник зсуву при скролі -->
<b data-count="1000">0</b>             <!-- анімований лічильник -->
```

Усе поважає `prefers-reduced-motion: reduce` — анімації вимикаються повністю.

## Зображення

Фото інтер'єру, команди та обладнання в `img/` — реальні знімки клініки.

Чотири студійні кадри (hero, паралакс-блок, галерея) згенеровані через
higgsfield і поки що підключені **прямими CDN-посиланнями**. Щоб покласти їх
у репозиторій і прибрати зовнішню залежність:

```bash
bash fetch-media.sh
```

## Прайс

Ціни в секції «Прайс-лист» перенесені з офіційного прайсу клініки (2026) і
розбиті на 4 категорії: загальна стоматологія, терапевтичне лікування,
ендодонтичне лікування, ортодонтія. Оновлюються прямо в `index.html`
у блоці `<section id="price">`.
